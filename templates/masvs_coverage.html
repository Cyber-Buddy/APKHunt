Zero controls are automatically verified end to end. Static matches start an investigation; they do not certify an app or prove a vulnerability.

How to read the map

Static signals identify a configuration or code lead. Inventory records relevant package facts without a security verdict. No control check means the scanner cannot assess that control's main property. Runtime, backend, or human evidence is needed before deciding whether an app meets a control.
